Core Requirement Test Scenarios

This page generates live scannable barcodes conforming to the 9 mandatory project testing scenarios. You can point your smartphone or webcam at the barcodes below or copy the ISBN to test manual lookup.

Test 1: Valid ISBN-13 (EAN-13)

Clean Code: A Handbook of Agile Software Craftsmanship

Author: Robert C. Martin
ISBN-13: 9780132350884

Expected Result: Scans instantly as EAN-13/ISBN-13. Retrieves title, author, Prentice Hall publisher, 2008 publication date, cover image, and category.
Test 2: Valid ISBN-10

The Pragmatic Programmer: From Journeyman to Master

Authors: Andrew Hunt, David Thomas
ISBN-10: 020161622X (EAN-13 barcode: 9780201616224)

Expected Result: Checksum with check character 'X' is validated modulo 11. Normalizes and converts to ISBN-13 9780201616224. Retrieves full details from API.
Test 3: Incomplete Book Info

Classic / Sparse Metadata Volume

Title: Calculus Made Easy
ISBN-13: 9781440058295

Expected Result: Successfully retrieves available fields. Missing fields (e.g. publisher or cover) clearly display as "Not available" rather than fabricated info.
Test 4: Invalid ISBN (Checksum Error)

Corrupted / Damaged Barcode Simulation

Invalid Code: 9780132350880 (Expected check: 4, given: 0)
Type: Modulo-10 Checksum Failure

Expected Result: System validates ISBN before calling API, rejects it immediately with error: "Invalid ISBN-13 check digit checksum", preventing wasted API calls.
Test 5: ISBN Not Found in Database

Uncataloged / Private Publisher Book

Valid Checksum ISBN: 9789999999993
Status: Syntactically valid, but zero results in Google & OpenLibrary

Expected Result: Displays required notice: "Book information could not be found for this ISBN. You can enter the book information manually." with 1-click manual entry.
Test 6: Duplicate Scan Prevention

JavaScript: The Good Parts

Author: Douglas Crockford
ISBN-13: 9780596517748

Expected Result: Add book once. Scan barcode a second time: System triggers duplicate warning modal asking user whether to add another copy or cancel.
Test 7: Learning JavaScript Design Patterns

Design Patterns by Addy Osmani

Author: Addy Osmani
ISBN-13: 9781449331818

Expected Result: Full bibliographic metadata retrieved, category tags formatted, cover image displayed, added to collection.

Permissions & Excel Export

Permission Denied & Excel Export Verification

Test (Excel Export): Click "Export to Excel" with multiple books in list → verifies downloaded file name format scanned_books_YYYY-MM-DD.xlsx and Excel columns.

Verification Checklist:
  • S/N, ISBN, Title, Author, Publisher, Publication Date columns
  • ISBN preserved as text without scientific notation
  • Auto column widths adjusted
